# Brand assets — put the OFFICIAL DAFWA logo here

| File | Used for | Recommended |
|------|----------|-------------|
| `logo.png` | Header, footer, order confirmation, admin login, apple-touch-icon | Transparent PNG, ~600px wide |
| `logo-light.png` *(optional)* | Footer on dark background | Cream/white version of the logo |
| `og-image.png` | Social sharing preview (WhatsApp, X, etc.) | 1200×630 |

Until `logo.png` exists, the site shows a typographic "دَفوة · DAFWA" wordmark.
For emails, set `EMAIL_LOGO_URL` (e.g. `https://your-domain/brand/logo.png`) in Netlify.
You can also replace `/favicon.svg` with a favicon generated from the logo.
